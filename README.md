# monsterdentist-legal

Rechtliche Seiten für die iOS-App **Monster Dentist**, gehostet über GitHub
Pages als **einzige** maßgebliche Quelle (keine veralteten Kopien in der App).

## Seiten

- `index.html` – Landing / Übersicht
- `privacy.html` – Datenschutzerklärung (DE + EN)
- `impressum.html` – Impressum (§ 5 DDG)
- `support.html` – Support / FAQ / Kontakt

## GitHub Pages aktivieren

1. Repo `monsterdentist-legal` auf GitHub anlegen (Account **MisterLG**) und
   diese Dateien pushen.
2. **Settings → Pages → Source: „Deploy from a branch"**, Branch `main`,
   Ordner `/ (root)`.
3. Nach ein paar Minuten sind die Seiten erreichbar unter
   `https://misterlg.github.io/monsterdentist-legal/…`.

Diese URLs sind bereits in `PRIVACY.md` und `APPSTORE.md` hinterlegt.
